In this module, you're introduced to general cloud concepts. You start with an introduction to the cloud in general. Then you dive into concepts like shared responsibility, different [[Glossary#Cloud model (deployment model)|cloud models]], and explore the unique pricing method for the cloud.

If you're already familiar with [[Glossary#Cloud computing|cloud computing]], this module may be largely review for you.

## Learning objectives

After completing this module, you'll be able to:

- Define [[Glossary#Cloud computing|cloud computing]].
- Describe the [[Glossary#Shared responsibility model|shared responsibility model]].
- Define [[Glossary#Cloud model (deployment model)|cloud models]], including public, private, and hybrid.
- Identify appropriate use cases for each [[Glossary#Cloud model (deployment model)|cloud model]].
- Describe the [[Glossary#Consumption-based model|consumption-based model]].
- Compare cloud pricing models.
