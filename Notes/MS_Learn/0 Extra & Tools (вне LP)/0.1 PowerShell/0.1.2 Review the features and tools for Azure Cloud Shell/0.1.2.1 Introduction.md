Instead of using the locally installed PowerShell module for managing Azure resources, you could also use the [[Glossary#Azure Cloud Shell|Azure Cloud Shell]] environment. This option lets you use PowerShell or Bash environments and commands to manage Azure resources. [[Glossary#Azure Cloud Shell|Azure Cloud Shell]] is available in the Azure portal and also in the Microsoft 365 admin portal. In this module, you'll learn about [[Glossary#Azure Cloud Shell|Azure Cloud Shell]] and its features.

## Learning objectives

After completing this module, you'll be able to:

- Describe [[Glossary#Azure Cloud Shell|Azure Cloud Shell]].
- Describe features and tools for [[Glossary#Azure Cloud Shell|Azure Cloud Shell]].
- Use [[Glossary#Azure Cloud Shell|Azure Cloud Shell]].

## Prerequisites

Familiarity with:

- Windows networking technologies and implementation
- Windows Server administration, maintenance, and troubleshooting
- [[Glossary#Windows PowerShell|PowerShell]] and its commands to perform specific tasks
- [[Glossary#PowerShell cmdlets|PowerShell cmdlets]] used for system administration tasks related to Active Directory, network configuration, server administration, and Windows client device administration
- [[Glossary#Windows PowerShell pipeline|PowerShell pipeline]], [[Glossary#PowerShell providers|PowerShell providers]], and [[Glossary#PowerShell drives|PowerShell drives]]
- [[Glossary#CIM|CIM]] and [[Glossary#WMI|WMI]] technologies
- Using variables, arrays, hash tables, and scripting constructs in PowerShell
- Administering remote computers with PowerShell.
