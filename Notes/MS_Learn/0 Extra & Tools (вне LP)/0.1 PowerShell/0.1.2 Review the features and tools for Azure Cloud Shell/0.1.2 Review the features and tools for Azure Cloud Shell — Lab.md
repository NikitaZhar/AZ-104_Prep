Hands-on по материалу модуля [[0.1.2 Review the features and tools for Azure Cloud Shell]]. Всё делается в браузере — локальная установка не нужна.

## Открыть Cloud Shell

- [ ] Открыть [[Glossary#Azure Cloud Shell|Azure Cloud Shell]] прямой ссылкой [https://shell.azure.com](https://shell.azure.com), либо иконкой Cloud Shell на панели [Azure portal](https://portal.azure.com).
- [ ] При запросе выбрать **PowerShell** как оболочку.
- [ ] В панели **Getting started** сравнить два пути: **Mount storage account** (постоянное хранилище) и **No storage account required** (эфемерная сессия). Выбрать монтирование хранилища.
- [ ] Если монтируешь: выбрать подписку → **Apply** → **We'll create a storage account for you** и пройти шаги создания новой resource group и storage account.

## Поработать в PowerShell-режиме

- [ ] Дождаться инициализации, затем вывести подписки:
  ```powershell
  Get-AzSubscription
  ```
- [ ] Вывести resource groups:
  ```powershell
  Get-AzResourceGroup
  ```

## Переключиться в Bash

- [ ] Кнопкой **Switch to Bash** в тулбаре переключиться на Bash и подтвердить выбор.
- [ ] Вывести подписки через Azure CLI (попробовать tab-completion):
  ```bash
  az account list
  ```
- [ ] Вывести ресурсы:
  ```bash
  az resource list
  ```

## Azure drive (только PowerShell)

- [ ] Вернуться в **PowerShell** и перейти на диск Azure:
  ```powershell
  cd Azure:
  ```
- [ ] Обновить список ресурсов и вернуться домой:
  ```powershell
  dir -Force
  cd ~
  ```

## Cloud Editor и хранилище

- [ ] Открыть Cloud Editor (или иконкой-карандашом **Editor** в тулбаре):
  ```
  code .
  ```
- [ ] Открыть файл **.profile**, посмотреть на баннере **Settings** (Text Size, Font, Upload/Download) и меню **...** (Save, Close Editor, Open File).
- [ ] Проверить, что смонтированная папка доступна как `$HOME\clouddrive`, и вспомнить: файлы вне `$HOME` и состояние машины между сессиями не сохраняются.
- [ ] Закрыть редактор и Cloud Shell; убедиться, что сессия завершается после ~20 минут простоя.
