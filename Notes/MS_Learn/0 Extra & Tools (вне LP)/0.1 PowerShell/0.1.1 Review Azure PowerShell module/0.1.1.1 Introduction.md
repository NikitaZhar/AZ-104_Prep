You can manage Microsoft Azure resources by using the Azure portal, which is usually the most common way of administration. However, for some tasks, [[Glossary#Azure PowerShell|Azure PowerShell]] is more convenient. In this module, you'll learn about the [[Glossary#Azure PowerShell|Azure PowerShell]] environment and the [[Glossary#Azure Az PowerShell module|Az module for PowerShell]]. Also, you'll learn about ways to manage [[Glossary#Microsoft Entra ID|Microsoft Entra ID]] by using PowerShell modules.

## Learning objectives

After completing this module, you'll be able to:
- Describe [[Glossary#Azure PowerShell|Azure PowerShell]].
- Describe the [[Glossary#Azure Az PowerShell module|Azure Az PowerShell module]].
- Install the [[Glossary#Azure Az PowerShell module|Azure Az PowerShell module]].
- Migrate [[Glossary#Azure PowerShell|Azure PowerShell]] from [[Glossary#AzureRM|AzureRM]] to Az.
- Describe the [[Glossary#Microsoft Graph PowerShell module|Microsoft Graph PowerShell module]] and how to use it for [[Glossary#Microsoft Entra ID|Microsoft Entra ID]] administration.

## Prerequisites

Familiarity with:
- Windows networking technologies and implementation
- Windows Server administration, maintenance, and troubleshooting
- [[Glossary#Windows PowerShell|Windows PowerShell]] and its commands to perform specific tasks
- [[Glossary#PowerShell cmdlets|PowerShell cmdlets]] used for system administration tasks related to Active Directory, network configuration, server administration, and Windows client device administration
- [[Glossary#Windows PowerShell pipeline|Windows PowerShell pipeline]], [[Glossary#PowerShell providers|PowerShell providers]], and [[Glossary#PowerShell drives|PowerShell drives]]
- [[Glossary#CIM|CIM]] and [[Glossary#WMI|WMI]] technologies
- Using variables, arrays, hash tables, and scripting constructs in [[Glossary#Windows PowerShell|Windows PowerShell]]
- Administering remote computers with [[Glossary#Windows PowerShell|Windows PowerShell]].
