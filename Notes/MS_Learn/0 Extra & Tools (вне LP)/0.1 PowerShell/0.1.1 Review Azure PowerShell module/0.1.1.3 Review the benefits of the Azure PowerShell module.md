The [[Glossary#Azure Az PowerShell module|Az PowerShell module]] is a set of [[Glossary#PowerShell cmdlets|cmdlets]] for managing Azure resources directly from PowerShell. PowerShell provides powerful features for automation that you can use to manage your Azure resources; for example, in the context of a continuous integration and continuous delivery ([[Glossary#CI/CD|CI/CD]]) pipeline.

The [[Glossary#Azure Az PowerShell module|Az PowerShell module]] is the replacement for [[Glossary#AzureRM|AzureRM]] and is the recommended version to use for interacting with Azure. To keep up with the latest Azure features in PowerShell, you should migrate to the [[Glossary#Azure Az PowerShell module|Az PowerShell module]].

>[!Note]
There's no support for having both the [[Glossary#AzureRM|AzureRM]] and [[Glossary#Azure Az PowerShell module|Az modules]] installed for PowerShell 5.1 on Windows at the same time.

## Benefits of the Az PowerShell module
The [[Glossary#Azure Az PowerShell module|Az PowerShell module]] features the following benefits:
- Security and stability:
    - Token cache encryption
    - Prevention of man-in-the-middle attack type
    - Support for authentication with Active Directory Federation Services ([[Glossary#AD FS|AD FS]]) in Windows Server 2019
    - Username and password authentication in PowerShell 7
    - Support for features such as continuous access evaluation
- Support for all Azure services:
    - All generally available Azure services have a corresponding supported PowerShell module
    - Multiple bug fixes and API version upgrades since [[Glossary#AzureRM|AzureRM]]
- New capabilities:
    - Support in [[Glossary#Azure Cloud Shell|Cloud Shell]] and cross-platform
    - Ability to get and use access tokens to access Azure resources
    - Cmdlets for advanced Representational State Transfer ([[Glossary#REST|REST]]) operations with Azure resources

The [[Glossary#Azure Az PowerShell module|Az PowerShell module]] is based on the .NET Standard library and works with PowerShell 7 and newer on all platforms including Windows, macOS, and Linux. It's also compatible with [[Glossary#Windows PowerShell|Windows PowerShell]] 5.1.

>[!Note]
PowerShell 7 and newer are the recommended versions of PowerShell for use with Az PowerShell on all platforms.

Az is the most current PowerShell module for Azure. You can log issues or feature requests directly on the GitHub repository. You can also contact Microsoft support if you have a support contract. Microsoft implements feature requests in the latest version of Az. Microsoft addresses critical issues in the last two versions of Az.

>[!Note]
[[Glossary#AzureRM|AzureRM]] PowerShell modules were officially deprecated on February 29, 2024. Although [[Glossary#AzureRM|AzureRM]] may still function, it's no longer maintained or supported. Migrate to the [[Glossary#Azure Az PowerShell module|Az PowerShell module]] to ensure continued support.
