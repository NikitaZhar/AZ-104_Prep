Hands-on по материалу модуля [[0.1.1 Review Azure PowerShell module]]. Делай в локальном PowerShell 7 или в [Azure Cloud Shell](https://shell.azure.com) (там модуль Az уже предустановлен).

## Az PowerShell: установка и вход

- [ ] Проверить версию PowerShell (нужен 7.x; на Windows подойдёт и 5.1):
  ```powershell
  $PSVersionTable.PSVersion
  ```
- [ ] Задать политику выполнения перед установкой:
  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  ```
- [ ] Установить модуль Az из PowerShell Gallery:
  ```powershell
  Install-Module -Name Az -Repository PSGallery -Force
  ```
- [ ] Войти в Azure:
  ```powershell
  Connect-AzAccount
  ```
- [ ] Повторить те же команды в [[Glossary#Azure Cloud Shell|Azure Cloud Shell]] (без локальной установки) и сравнить.
- [ ] Обновить модуль тем же методом, что и ставил:
  ```powershell
  Update-Module -Name Az
  ```

## Microsoft Graph PowerShell (администрирование Entra)

- [ ] Установить модуль:
  ```powershell
  Install-Module Microsoft.Graph
  ```
- [ ] Подключиться к Microsoft Entra:
  ```powershell
  Connect-MgGraph -Scopes 'User.Read.All'
  ```

## Миграция AzureRM → Az (если есть старые скрипты)

- [ ] Посмотреть установленные версии [[Glossary#AzureRM|AzureRM]]:
  ```powershell
  Get-Module -Name AzureRM -ListAvailable -All
  ```
- [ ] Установить набор миграции и сгенерировать план (до правок):
  ```powershell
  Install-Module -Name Az.Tools.Migration
  ```

> Не держи [[Glossary#AzureRM|AzureRM]] и Az одновременно на [[Glossary#Windows PowerShell|Windows PowerShell]] 5.1 — это не поддерживается.
