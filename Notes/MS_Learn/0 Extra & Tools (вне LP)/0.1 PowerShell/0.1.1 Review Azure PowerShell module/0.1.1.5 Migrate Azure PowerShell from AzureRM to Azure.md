Scripts created for the [[Glossary#AzureRM|AzureRM]] [[Glossary#PowerShell cmdlets|cmdlets]] won't automatically work with the [[Glossary#Azure Az PowerShell module|Az module]]. To make the transition easier, the [[Glossary#AzureRM|AzureRM]] to `Az migration toolkit` was developed. No migration to a new command set is ever convenient, but it's important that you understand how to transition to the [[Glossary#Azure Az PowerShell module|Az PowerShell module]].
The new [[Glossary#PowerShell cmdlets|cmdlet]] names have been designed to be easier to learn. Instead of using AzureRm or Azure in [[Glossary#PowerShell cmdlets|cmdlet]] names, you use Az [[Glossary#PowerShell cmdlets|cmdlets]]. For example, the old [[Glossary#PowerShell cmdlets|cmdlet]] **New-AzureRMVm** has become **New-AzVm**. However, migration is more than just becoming familiar with the new [[Glossary#PowerShell cmdlets|cmdlet]] names. There are renamed modules, parameters, and other important changes.
Before taking any migration steps, check which versions of [[Glossary#AzureRM|AzureRM]] are installed on your system. Doing so allows you to make sure scripts are already running on the latest release and let you know which versions of [[Glossary#AzureRM|AzureRM]] must be uninstalled.
To check which versions of [[Glossary#AzureRM|AzureRM]] you've installed, run the following command:

PowerShell
```
Get-Module -Name AzureRM -ListAvailable -All
```

>[!Note]
The latest available release of [[Glossary#AzureRM|AzureRM]] is 6.13.1. If you don't have this version installed, your existing scripts might need additional modifications to work with the [[Glossary#Azure Az PowerShell module|Az module]].

The recommended option to migrate from [[Glossary#AzureRM|AzureRM]] to the [[Glossary#Azure Az PowerShell module|Az PowerShell module]] is to use automatic migration. For this, you need to install the [[Glossary#AzureRM|AzureRM]] to Az migration toolkit by running the following command:

PowerShell
```
Install-Module -Name Az.Tools.Migration
```

With the [[Glossary#AzureRM|AzureRM]] to Az migration toolkit, you can generate a plan to determine what changes will be performed on your scripts before making any modifications to them and before installing the [[Glossary#Azure Az PowerShell module|Az PowerShell module]].

> **Additional reading:** To learn about the steps for automatic migration, refer to [Quickstart: Automatically migrate PowerShell scripts from AzureRM to the Az PowerShell module](https://aka.ms/quickstart-automatically-migrate-powershell-scripts-from-azurerm-to-the-az-powershell-module).

You can also use Microsoft Visual Studio Code to migrate your existing scripts. To do so, you first need to install the [[Glossary#Azure PowerShell|Azure PowerShell]] extension for Visual Studio Code. Then, you need to perform the following steps:

1. Load your [[Glossary#AzureRM|AzureRM]] script in Visual Studio Code.
2. Open the command palette by selecting **Ctrl+Shift+P**.
3. Select the **Migrate [[Glossary#Azure PowerShell|Azure PowerShell]]** script.
4. Select the **[[Glossary#AzureRM|AzureRM]]** source version.
5. Follow the recommended actions for each underlined command or parameter.
