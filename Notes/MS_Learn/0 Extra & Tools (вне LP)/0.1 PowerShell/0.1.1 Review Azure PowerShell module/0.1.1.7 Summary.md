In this module, you learned about the [[Glossary#Azure PowerShell|Azure PowerShell]] environment and the [[Glossary#Azure Az PowerShell module|Az module]] for PowerShell. Also, you learned about ways to manage [[Glossary#Microsoft Entra ID|Microsoft Entra ID]] by using PowerShell modules. The following are the key takeaways:

- [[Glossary#Azure PowerShell|Azure PowerShell]] is a module that you add to [[Glossary#Windows PowerShell|Windows PowerShell]] or PowerShell 7 to let you connect to your Azure subscription and manage resources. It provides a set of [[Glossary#PowerShell cmdlets|cmdlets]] that you can use to manage and administer Azure resources directly from the PowerShell command line.
    
- The [[Glossary#Azure Az PowerShell module|Az PowerShell module]] is a set of [[Glossary#PowerShell cmdlets|cmdlets]] for managing Azure resources directly from PowerShell.
    
- The [[Glossary#Azure Az PowerShell module|Azure Az PowerShell module]] is a rollup module. Installing it downloads the available [[Glossary#Azure Az PowerShell module|Az PowerShell modules]] and makes their [[Glossary#PowerShell cmdlets|cmdlets]] available for use. The [[Glossary#Azure Az PowerShell module|Azure Az PowerShell module]] works with PowerShell 7.x and newer versions on all platforms.
    
- The [[Glossary#Microsoft Graph PowerShell module|Microsoft Graph PowerShell module]] provides [[Glossary#PowerShell cmdlets|cmdlets]] that you can use for [[Glossary#Microsoft Entra ID|Microsoft Entra ID]] administrative tasks such as user management, domain management, and configuring single sign-on.
