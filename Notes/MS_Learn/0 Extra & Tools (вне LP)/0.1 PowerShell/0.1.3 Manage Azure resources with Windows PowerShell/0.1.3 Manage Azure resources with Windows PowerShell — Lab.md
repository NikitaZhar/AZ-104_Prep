Hands-on по материалу модуля [[0.1.3 Manage Azure resources with Windows PowerShell]]. Делай в локальном PowerShell 7.2+ с модулем [[Glossary#Azure Az PowerShell module|Az]] или в [[Glossary#Azure Cloud Shell|Azure Cloud Shell]] (там Az уже предустановлен). Ресурсы создаются платно — в конце всё удаляется.

## Вход и resource group

- [ ] Войти в Azure (только для локального PowerShell; в Cloud Shell не нужно):
  ```powershell
  Connect-AzAccount
  ```
- [ ] Создать [[Glossary#Resource group|resource group]]:
  ```powershell
  New-AzResourceGroup -ResourceGroupName "myResourceGroup" -Location "westeurope"
  ```

## Создать VM

- [ ] Сохранить учётные данные локального администратора VM:
  ```powershell
  $cred = Get-Credential
  ```
- [ ] Задать параметры хэш-таблицей и создать VM через splatting:
  ```powershell
  $vmParams = @{
    ResourceGroupName   = 'myResourceGroup'
    Name                = 'TestVM'
    Location            = 'westeurope'
    ImageName           = 'Win2022AzureEdition'
    PublicIpAddressName = 'TestPublicIp'
    Credential          = $cred
    OpenPorts           = 3389
  }
  New-AzVM @vmParams
  ```
- [ ] Узнать публичный IP и подключиться по RDP:
  ```powershell
  Get-AzPublicIpAddress -ResourceGroupName "myResourceGroup" | Select IpAddress
  mstsc /v:publicIpAddress
  ```

## Управление VM

- [ ] Посмотреть доступные размеры в регионе и для VM:
  ```powershell
  Get-AzVMSize -Location "westeurope"
  Get-AzVMSize -ResourceGroupName "myResourceGroup" -VMName "TestVM"
  ```
- [ ] Изменить размер VM (VM перезагрузится):
  ```powershell
  $vm = Get-AzVM -ResourceGroupName "myResourceGroup" -VMName "TestVM"
  $vm.HardwareProfile.VmSize = "Standard_DS3_v2"
  Update-AzVM -VM $vm -ResourceGroupName "myResourceGroup"
  ```
- [ ] Остановить/деаллоцировать и снова запустить:
  ```powershell
  Stop-AzVM -ResourceGroupName "myResourceGroup" -Name "TestVM" -Force
  Start-AzVM -ResourceGroupName "myResourceGroup" -Name "TestVM"
  ```
- [ ] Добавить data disk (config → disk → attach → commit):
  ```powershell
  $diskConfig = New-AzDiskConfig -Location "westeurope" -CreateOption Empty -DiskSizeGB 128
  $dataDisk = New-AzDisk -ResourceGroupName "myResourceGroup" -DiskName "myDataDisk" -Disk $diskConfig
  $vm = Get-AzVM -ResourceGroupName "myResourceGroup" -Name "TestVM"
  $vm = Add-AzVMDataDisk -VM $vm -Name "myDataDisk" -CreateOption Attach -ManagedDiskId $dataDisk.Id -Lun 1
  Update-AzVM -ResourceGroupName "myResourceGroup" -VM $vm
  ```

## Хранилище

- [ ] Создать general-purpose storage account с LRS, получить контекст:
  ```powershell
  $storageAccount = New-AzStorageAccount -ResourceGroupName "myResourceGroup" `
    -Name "mystorageacct$(Get-Random)" -SkuName Standard_LRS -Location "westeurope"
  $ctx = $storageAccount.Context
  ```
- [ ] Создать приватный blob-контейнер (публичный доступ по умолчанию заблокирован на уровне аккаунта):
  ```powershell
  New-AzStorageContainer -Name "quickstartblobs" -Context $ctx -Permission Off
  ```
- [ ] Изменить тип аккаунта:
  ```powershell
  Set-AzStorageAccount -ResourceGroupName "myResourceGroup" -AccountName $storageAccount.StorageAccountName -Type "Standard_RAGRS"
  ```

## Подписки и контекст

- [ ] Посмотреть подписки и переключить контекст:
  ```powershell
  Get-AzSubscription
  Set-AzContext -Subscription "xxxx-xxxx-xxxx-xxxx"
  ```

## Уборка

- [ ] Удалить всё, что создано в resource group:
  ```powershell
  Remove-AzResourceGroup -Name "myResourceGroup" -Force
  ```
