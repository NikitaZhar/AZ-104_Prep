Azure virtual machines (VMs) provide a fully configurable and flexible computing environment. You can create and manage these VMs by using the Azure portal, PowerShell with the [[Glossary#Azure Az PowerShell module|Az module]], or the [[Glossary#Azure Cloud Shell|Cloud Shell]] environment. In this module, you'll learn how to create and manage Azure VMs by using PowerShell.

Besides managing Azure VMs, one of the most common usages of the PowerShell [[Glossary#Azure Az PowerShell module|Az module]] is to manage Azure storage accounts and Azure subscriptions. In this lesson, you'll also learn about managing Azure storage accounts and Azure [[Glossary#Subscription|subscriptions]] with PowerShell.

## Learning objectives

After completing this module, you'll be able to:

- Create Azure VMs with PowerShell.
- Manage Azure VMs and their resources with PowerShell.
- Manage Azure storage accounts with PowerShell.
- Manage Azure subscriptions with PowerShell.

## Prerequisites

Familiarity with:

- Windows networking technologies and implementation
- Windows Server administration, maintenance, and troubleshooting
- [[Glossary#Windows PowerShell|Windows PowerShell]] and its commands to perform specific tasks
- [[Glossary#PowerShell cmdlets|PowerShell cmdlets]] used for system administration tasks related to Active Directory, network configuration, server administration, and Windows 10 or Windows 11 device administration
- [[Glossary#Windows PowerShell pipeline|Windows PowerShell pipeline]], [[Glossary#PowerShell providers|PowerShell providers]], and [[Glossary#PowerShell drives|PowerShell drives]]
- [[Glossary#CIM|CIM]] and [[Glossary#WMI|WMI]] technologies
- Using variables, arrays, hash tables, and scripting constructs in [[Glossary#Windows PowerShell|Windows PowerShell]]
- Administering remote computers with [[Glossary#Windows PowerShell|Windows PowerShell]]
