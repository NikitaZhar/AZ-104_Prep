In this module, you learned how to create and manage Azure VMs by using PowerShell and manage Azure storage accounts and Azure [[Glossary#Subscription|subscriptions]] with PowerShell. The following are the key takeaways:

- You can create a new Azure virtual machine (VM) with PowerShell commands, by using the locally installed PowerShell with the [[Glossary#Azure Az PowerShell module|Az module]]. You can also use the [[Glossary#Azure Cloud Shell|Cloud Shell]] environment that's available in Azure portal.
- You can also use PowerShell commands to manage, modify, and remove Azure VMs and the resources related to Azure VMs.
- You can use [[Glossary#Azure PowerShell|Azure PowerShell]] to manage Azure-related storage. Before you start managing your storage, you should first create a storage account, if you don't have one. Usually, storage accounts are created automatically when you create other Azure resources such as Azure virtual machines (VMs).
- Generally, most Azure users only have a single [[Glossary#Subscription|subscription]]. However, you might have multiple [[Glossary#Subscription|subscriptions]] within Azure for any of the following reasons:
    - You're part of more than one organization.
    - Your organization divides access to certain resources across groupings.
